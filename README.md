# Pub-Order

Pub-Order is a web application designed to make ordering food from Vanderbilt's Pub faster and more convenient for students.

The goal of the project is to allow students to view available menu items, place an order, and track their pickup status without having to wait in line.

## Features

- Student login and authentication
- View current menu items
- Add items to a cart
- Place food orders
- View order status
- Estimated wait times
- Simple interface designed for Vanderbilt students

## Project Structure

The project will be divided into a frontend and backend.

The frontend will handle the user interface and communicate with the backend through API requests.

The backend will handle application logic, authentication, order processing, and communication with the database.
